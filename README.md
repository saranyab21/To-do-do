# Master's Thesis

Research repository for my Master's thesis in Artificial Intelligence.

## Project structure

- docs/: Research papers, proposal and meeting notes
- data/: Datasets
- src/: Research implementation
- experiments/: Experiment configurations and outputs
- notebooks/: Exploratory analysis
- results/: Evaluation results and figures
- tests/: Unit and integration tests
- thesis/: Dissertation chapters
- scripts/: Utility scripts

## Environment

Python virtual environment: .venv

## Reproducibility

Research experiments should use documented configurations,
fixed random seeds where appropriate, and reproducible evaluation.
